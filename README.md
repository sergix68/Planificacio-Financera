# Futur · Planificador financer

Projecte en dues capes:

- `engine/`: motor Python amb projecció, polítiques de retirada i base Monte Carlo.
- `web/`: interfície web responsive preparada per a iPad i instal·lació com a app web.
- `Futur.xlsx`: model original, conservat com a font de dades i referència de validació.

La primera interfície web reprodueix el punt de partida de l’Excel i permet provar escenaris de forma tàctil. La següent iteració connectarà el dashboard amb el motor Monte Carlo Python i afegirà la comparació d’estratègies.
